
# 🤖 Agentic AI Feedback Analysis System

An end-to-end multi-agent AI system that automatically analyzes, classifies, prioritizes, and routes customer feedback using Large Language Models (LLMs).

This project demonstrates how Agentic AI can simulate collaborative decision-making between multiple intelligent agents to automate real-world business workflows.

---

# 🚀 Project Overview

Organizations receive thousands of customer feedback messages daily.
Manually analyzing them is slow, expensive, and inconsistent.

This Agentic AI system solves that problem by creating specialized AI agents that work together like a virtual operations team.

The system:

* Classifies customer feedback
* Detects bugs and issues
* Assigns severity and priority
* Routes requests to appropriate teams
* Generates automated insights
* Provides an interactive Gradio UI

---

# 🧠 Agentic AI Architecture

The project uses multiple autonomous AI agents:

### 1. Classifier Agent

* Categorizes feedback into:

  * Bug
  * Feature Request
  * Praise
  * Complaint
  * Spam
* Uses LLM reasoning for intelligent classification

### 2. Bug Analysis Agent

* Analyzes bug severity
* Assigns priority levels:

  * Critical
  * High
  * Medium
  * Low
* Estimates business impact

### 3. Routing/Decision Logic

* Routes issues to appropriate teams
* Creates structured outputs for operations workflows
